# LWM LLR 预测 —— 开发与评估报告（Sionna PUSCH 版）

> **当前版本 v3（多配置自适应版）**：一个模型适配 天线 1/2/4/8 × RB 1~10 ×
> 符号 3~14 × DMRS {1}/{1+1}/{1+2} × TDL-A/B/C/D × 时延/多普勒；固定 10MHz
> 系统带宽（1024-FFT），信道场景多样性与 Sionna 原生实现；LLR Decoder 为
> CNN 残差网络（NNreceiver 架构）+ BCE 损失 + 配置元数据通道。
> v2（固定配置 CNN+BCE）结果保留在 §4.2，v1（残差 MLP+MSE）见 §4.3。

## 0. v3 多配置升级（当前版本）

### 0.1 升级内容

| # | 升级点 | 实现（Sionna 原生） |
|---|--------|---------------------|
| 1 | **信道场景多样性** | TDL-A/B/C/D × 时延 {30,100,300}ns × 多普勒（`min_speed/max_speed` Jakes 采样，0/58/350Hz @3.5GHz） |
| 2 | **接收天线灵活** | 1/2/4/8 四种（模型输入补零到 8，patch 维度恒 16 复用官方 embedding） |
| 3 | **子载波按 RB 分配** | 1~10 RB（12~120 子载波），tokenizer 序列长度自适应（≤121 ≤ MAX_LEN=129） |
| 4 | **符号数 3~14** | `symbol_allocation=[0,n]`：3 符号用 mapping type B（l0=0），4~14 用 type A（l0=2），DMRS 位置自动调整 |
| 5 | **DMRS 三模式** | `additional_position` 0/1/2 → {1} / {1+1} / {1+2}，数据 RE 索引取自 `pilot_pattern.mask` |
| 6 | **固定系统带宽** | BWP 嵌入 **1024-FFT 系统网格**（≈10MHz，15.36MHz 采样，CP 72 样本），信道按系统带宽建模 |
| 7 | **一个模型适配** | LWM 骨干长度自适应 + CNN Decoder 全卷积（尺寸无关）+ 配置元数据 cfg 通道 + 数据 RE 索引随样本传入 |

### 0.2 关键技术问题与解决（Sionna 原生限制）

1. **窄带 OFDM 循环前缀破坏**：Sionna 默认信道时延参数 `l_min=-6, l_max=ceil(3µs·W)+6`
   的裕量在窄带采样率下远超 CP（1RB：±33µs vs CP 5.56µs）→ 固定带宽方案根治：
   1024-FFT 采样 15.36MHz 下裕量仅 0.39µs ≪ CP 4.7µs，且 `TimeChannel` 显式指定
   `l_min=0, l_max=min(ceil(τ_max·W), CP)`。
2. **短 PUSCH 数据 RE 索引**：`pusch.dmrs_mask` 是 14 符号全帧掩码（短 PUSCH 不匹配），
   改用 `rg.pilot_pattern.mask`（按实际分配符号数）。
3. **l_min<0 时解调输出多出符号**：`OFDMDemodulator` 按 `输入长度//符号长度` 切块，
   帧尾残留符号裁剪到 `rg.num_ofdm_symbols`。
4. **小数据下多配置欠拟合**：每配置组合生成 8 个不同样本（组内多样本）+ 配置元数据
   通道（接收机已知的系统参数）+ 40 epoch 大规模训练。

> 20dB 劣化（0.17 vs 0.05），验证了"每配置多样本 + cfg 通道 + 大规模训练"的必要性。

## 1. 数据建模修复（本版核心）

根据要求，数据建模已从自研 NumPy 仿真**迁移到标准 Sionna 2.x（PyTorch 后端）**：

| 项 | 旧版（自研） | **新版（Sionna 标准库）** |
|----|-------------|--------------------------|
| 链路 | 简化 OFDM | **标准 5G NR PUSCH**（`sionna.phy.nr.PUSCHTransmitter`） |
| 信道 | 自研 TDL-C | **TDL-A**（`sionna.phy.channel.tr38901.TDL` + `TimeChannel`，3GPP TR 38.901） |
| 导频 | comb-4 | **DMRS type1, {1+1} 双符号**（`PUSCHDMRSConfig`: 符号2+11, 2 CDM 组） |
| 信道估计 | LS-DFT | **LS + 线性插值**（`PUSCHLSChannelEstimator`，先估计后插值） |
| 模型输入 | (8, 128) 2D | **{num_rx, num_sc, num_symb} = (8, 120, 14) 3D 完整频域信道** |
| 数据 RE | 96/块 | 1440（12 数据符号 × 120 子载波） |
| SCS | 30 kHz | 15 kHz（NR mu=0） |
| 依赖 | — | `pip install sionna`（纯 PyTorch，无需 TensorFlow） |

## 3.5 GPU 大规模训练（本版升级）

环境 CUDA 可用性确认（RTX 3060 Laptop, sm_86, 6GB, CUDA 13.2 / torch 2.13+cu130）：
- 此前 GPU 处于 "requires reset" 状态（驱动层面异常），现已恢复（显示服务器正常占用 GPU）

## 3.6 性能优化（v2，当前版本）

根据优化要求对模型做了三项改动：

| # | 优化点 | 改动前（v1） | 改动后（v2） |
|---|--------|-------------|-------------|
| 1 | **降低推理复杂度** | Decoder 输入含 `llr_base`（需完整传统软解调） | **移除 llr_base**，输入仅 `[channel_emb + H_patch + Re/Im(z) + σ² + mod_onehot]` |
| 2 | **Decoder 架构** | 逐子载波 MLP（95 维 → 8 维） | **CNN 残差网络**（参考 NNreceiver）：GroupNorm + 首层 3×3 转置卷积 → 11 个残差块（空洞可分离卷积，out_channels [64,64,128,128,256,256,256,128,128,64,64]，dilation [(1,1),(1,1),(2,3),(2,3),(2,3),(3,6),(2,3),(2,3),(2,3),(1,1),(1,1)]）→ 3×3 卷积输出 8 bit logits；在**全网格 (14 符号 × 120 子载波)** 上处理，利用空间/频率上下文 |
| 3 | **损失函数** | MSE（回归理想 max-log LLR） | **BCE**（标签 = 真实传输 0/1 bit），模型输出即 LLR logits（正=bit1） |

- 特征图通道：emb(64) + H_patch(16) + Re(z) + Im(z) + σ² + mod_oh(4) = 87，补零到 88 满足 GroupNorm(groups=2)
- Decoder 参数 714K，总模型 1.32M（v1 总模型 1.19M）
- z 仅在数据 RE 位置有值（其余为 0），CNN 通过空洞卷积利用邻近 RE 上下文

### 训练结果（GPU，3000 样本，30 epoch，每模型 ~38 min）

| 模型 | val BCE | val 准确率 | 说明 |
|------|---------|-----------|------|
| 主模型（继续预训练） | 0.620 → **0.244** | 0.62 → 0.89 | BCE 持续下降 |
| 对照（官方权重） | 0.621 → **0.243** | 0.62 → 0.89 | 与主模型基本一致 |

> 注：验证集为全 SNR 混合（含大量高调制低 SNR 硬样本），val 准确率 0.89 对应 BER ≈ 0.11。

## 4. 性能评估

### 4.1 v3 评估结果（当前版本，多配置自适应）

**硬判决 BER（越低越好，48 样本 = 6 SNR × 8 配置循环）**：

| SNR | 传统基线 | **LWM+CNN (v3)** | 改善 | 对照(noPT) |
|-----|---------|-----------------|------|-----------|
| -5 dB | 0.3829 | 0.3457 | **-9.7%** | 0.3484 |
| 0 dB | 0.3585 | 0.2813 | **-21.5%** ✅ | 0.2699 |
| 5 dB | 0.2369 | 0.1640 | **-30.8%** ✅ | 0.1560 |
| 10 dB | 0.1438 | 0.0810 | **-43.7%** ✅ | 0.0608 |
| 15 dB | 0.1371 | 0.0717 | **-47.7%** ✅ | 0.0557 |
| 20 dB | 0.1109 | 0.0820 | **-26.1%** ✅ | 0.0607 |

**按配置维度（BER, 全 SNR 平均，lwm vs base）**：

| 维度 | 改善 |
|------|------|
| 天线 1/2/4/8 | 0.333→0.259 / 0.198→0.154 / 0.215→0.159 / 0.167→0.112（-22%~-33%） |
| RB 1~10 | 1RB 0.260→0.207，2RB 0.262→0.193，4RB 0.170→0.111，10RB 0.208→0.166（全 RB 改善） |
| 符号 3~14 | 3symb 0.164→0.109，7symb 0.280→0.219，14symb 0.171→0.113（全改善） |
| DMRS {1}/{1+1}/{1+2} | 0.259→0.196 / 0.224→0.167 / 0.189→0.139（全改善） |
| TDL-A/B/C/D | 0.333→0.259 / 0.198→0.154 / 0.215→0.159 / 0.167→0.112（全改善） |
| 速度 0/5/30 m/s | 0.259→0.196 / 0.224→0.167 / 0.189→0.139（全改善） |

**LLR 指标**（BCE logits 与 max-log 尺度不同，MSE 仅参考）：base MSE=5.52 / corr=0.855；lwm MSE=73.5 / corr=0.699；对照 MSE=62.9 / corr=0.732。

**结论与已知现象**：

1. **一个模型适配所有配置成功**：-5~20 dB 全区间 BER 改善 9.7%~47.7%（此前小规模版在 20dB 劣化），各配置维度（天线/RB/符号/DMRS/TDL/多普勒）全部无劣化。
2. **高 SNR 增益最大**（10~15dB ~ -44%~-48%）：多配置大规模训练 + 每组合多样本使模型学到了对各配置的信道估计误差修正。
3. **对照（无继续预训练）仍略优于主模型**（10~20dB）：MCM 预训练在 2000 样本/15 epoch 下对骨干帮助有限，骨干 lr=1e-6 过小的问题依旧（见 §6）。
4. 评估采样：每 SNR 8 样本按配置循环覆盖（含 1rx/1RB 等困难配置），基线 BER 显著高于固定配置版（0.11@20dB vs 0.04），更贴近真实部署难度。

### 4.2 v2 评估结果（历史：固定配置 CNN+BCE，10RB/14符号/8天线）

**硬判决 BER（越低越好）**：

| SNR | 传统基线 | **LWM+CNN (v2)** | 改善 | 对照(noPT) |
|-----|---------|-----------------|------|-----------|
| -5 dB | 0.2614 | 0.2390 | **-8.6%** | 0.2377 |
| 0 dB | 0.1733 | **0.0818** | **-52.8%** ✅ | 0.0821 |
| 5 dB | 0.0890 | **0.0217** | **-75.6%** ✅ | 0.0218 |
| 10 dB | 0.1572 | **0.0020** | **-98.7%** ✅ | 0.0020 |
| 15 dB | 0.0527 | **0.0002** | **-99.6%** ✅ | 0.0002 |
| 20 dB | 0.0409 | **0.0003** | **-99.3%** ✅ | 0.0003 |

**按调制阶数（全 SNR 平均 BER）**：4QAM 0.0678 → 0.0759（⚠️ 轻微回退 +12%）；16QAM 0.0000 → 0.0004；64QAM 0.2102 → **0.0639（-70%）**；256QAM 0.2227 → **0.0355（-84%）**。

**LLR 指标**（BCE logits 与 max-log 参考尺度不同，MSE 仅参考）：base MSE=4.30 / corr=0.964；lwm MSE=76.8 / corr=0.820（形状相似度低于基线，但硬判决正确率远超基线——模型学的是后验概率 LLR，尺度与 max-log 不同，对软判决译码反而是更优校准）。

**结论与已知现象**：

1. **数量级提升**：BCE + CNN 残差网络使 0~20 dB BER 改善 53%~99.6%（v1 仅 13~20%）；10~20 dB 已接近理想标签（llr_ref 硬判决）水平。
2. **高调制受益最大**：64QAM/256QAM 是传统基线的最大短板，正是 CNN 空间上下文 + 信道先验增益最大的地方。
3. **4QAM 低 SNR 轻微回退**（128 样本中 102 个略差）：QPSK 低 SNR 下模型输出的后验 LLR 在决策边界附近有偏置。后续可对 QPSK 样本加权或 SNR 条件化训练（见 §6）。
4. **评估采样说明**：每 SNR 50 样本按 32+18 两个 batch 随机调制（16QAM 仅在 20 dB 批次被抽中 → 基线零误差；10 dB 只有 64/256QAM → 基线 BER 非单调），属采样效应而非系统现象。
5. **继续预训练增益依旧不明显**（主 vs 对照差异 <0.5%），骨干 lr=1e-6 过小的问题仍未解决。

### 4.3 v1 评估结果（历史：残差 MLP + MSE 训练）

### LLR MSE（vs 理想 max-log，越小越好）

| 方案 | MSE | vs 基线 |
|------|-----|---------|
| 传统基线（H_est） | 4.260 | — |
| **LWM+Decoder（本方案）** | **3.442** | **-19.2%** ✅ |
| LWM 对照（无继续预训练） | 3.404 | -20.1% |

### 硬判决 BER（越低越好）

| SNR | 传统基线 | **LWM+Decoder** | 改善 |
|-----|---------|-----------------|------|
| -5 dB | 0.263 | 0.259 | -1.5% |
| 0 dB | 0.174 | 0.170 | -2.3% |
| 5 dB | 0.091 | **0.078** | **-13.8%** ✅ |
| **10 dB** | 0.161 | **0.128** | **-20.2%** ✅ |
| 15 dB | 0.051 | **0.042** | **-18.4%** ✅ |
| 20 dB | 0.040 | **0.035** | **-12.9%** ✅ |

按调制阶数（全 SNR 平均 BER）：64QAM 0.212→0.186（-12%），256QAM 0.226→0.202（-11%）。

### 结论

1. **大规模 GPU 训练带来显著提升**：LLR MSE 从 CPU 版的 -2.1% 提升到 **-19.2%**；BER 在 **5~20 dB 全区间改善 13~20%**（CPU 版仅 10dB 改善 18%）。数据量（3000 vs 1200）、epoch（30 vs 12）、更充分的 MCM 域适配（loss 0.426 vs 0.482）共同作用。
2. **残差设计保证不劣化**：所有 SNR 上 LWM 均不劣于基线。
3. **继续预训练增益依旧不明显**（主 vs 对照 <1.5%）：骨干微调 lr=1e-6 过小。后续建议提高骨干 lr（1e-4 量级）或两阶段训练（先冻骨干训 decoder，再联合微调），以充分发挥 MCM 域适配价值。

## 6. 后续改进

1. 加强 MCM 继续预训练（epoch 50+ / 骨干 lr 1e-4），验证域适配价值（v2 下主/对照仍 <0.5%）
2. 接入 LDPC 译码测 BLER（端到端指标）——v2 的 LLR 是后验概率 logits，天然适合软判决译码
3. **解决 4QAM 低 SNR 回退**：QPSK 样本加权、SNR 条件化（把 SNR 作为额外输入）、或对 QPSK 单独校准
4. 增加信道场景多样性（TDL-B/C/D、多普勒、多 UE）
5. 试 LMMSE 插值器（`LMMSEInterpolator`）作为更强基线
6. 模型结构探索：CNN decoder 的可分离卷积开关、dilation 配置、更浅骨干特征

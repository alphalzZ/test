# LWM LLR 预测 —— 开发与评估报告（多配置自适应版）

## 1. 项目概述

基于 **LWM（Large Wireless Model，wi-lab/lwm）** 信道基础模型与 **CNN 残差网络**（参考 NNreceiver 架构），在标准 **Sionna 5G NR PUSCH** 链路上实现**逐比特 LLR 预测**（软解调增强）：

- **一个模型适配所有系统参数**：接收天线 1/2/4/8 × 子载波 1~10 RB × OFDM 符号 3~14 × DMRS {1}/{1+1}/{1+2} × TDL-A/B/C/D × 时延 {30,100,300}ns × 多普勒（0~350Hz）
- **固定系统带宽**：BWP 嵌入 1024-FFT 系统网格（≈10MHz 载波，15.36MHz 采样）
- **无传统软解调**：模型输入不含 llr_base，直接预测后验概率 LLR（BCE 监督真实 0/1 bit）

## 2. 数据建模（Sionna 原生实现）

| 环节 | 实现 |
|------|------|
| 链路 | 标准 5G NR PUSCH（`sionna.phy.nr.PUSCHTransmitter`） |
| 信道 | TDL-A/B/C/D（`TDL` + `TimeChannel`，3GPP TR 38.901），多普勒用 `min_speed/max_speed` Jakes 采样 |
| 导频 | DMRS type1，{1}/{1+1}/{1+2}（`additional_position` 0/1/2，2 CDM 组） |
| 符号数 | 3~14（3 符号用 mapping type B，4~14 用 type A，`symbol_allocation`） |
| 信道估计 | LS + 线性插值（`PUSCHLSChannelEstimator`，先估计后插值） |
| 系统带宽 | BWP（1~10 RB）嵌入 1024-FFT 网格（≈10MHz，CP 72 样本），信道按系统带宽建模 |
| 均衡 | MMSE（n_rx→1），逐数据 RE |
| 标签 | 真实传输 0/1 bit（`bits_tx`）；参考 LLR 为理想信道 max-log（评估用） |

### 关键技术问题与解决（Sionna 原生限制）

1. **窄带 OFDM 循环前缀破坏**：Sionna 默认信道时延参数 `l_min=-6, l_max=ceil(3µs·W)+6`
   的裕量在窄带采样率下远超 CP（1RB：±33µs vs CP 5.56µs）→ 固定带宽方案根治：
   1024-FFT 采样 15.36MHz 下裕量仅 0.39µs ≪ CP 4.7µs，且 `TimeChannel` 显式指定
   `l_min=0, l_max=min(ceil(τ_max·W), CP)`。
2. **短 PUSCH 数据 RE 索引**：`pusch.dmrs_mask` 是 14 符号全帧掩码（短 PUSCH 不匹配），
   改用 `rg.pilot_pattern.mask`（按实际分配符号数）。
3. **l_min<0 时解调输出多出符号**：`OFDMDemodulator` 按 `输入长度//符号长度` 切块，
   帧尾残留符号裁剪到 `rg.num_ofdm_symbols`。
4. **小数据下多配置欠拟合**：每配置组合生成 8 个不同样本（组内多样本）+ 配置元数据
   通道（接收机已知的系统参数）+ 大规模训练。

## 3. 模型设计

### 3.1 输入与 Tokenizer（多配置自适应）

- **信道输入**：`H_est (n_rx, n_sc, n_symb)` 完整频域信道估计（维度随配置变化）
- **Token**：单子载波天线向量 `[Re(H[:,k]); Im(H[:,k])]`，天线不足 8 补零 → 恒 16 维
  （与官方 LWM `element_length=16` 一致，直接复用官方 embedding 权重）
- **序列**：`[CLS] + patches`，长度 `n_sc+1` 自适应（≤121 ≤ LWM MAX_LEN=129），逐 OFDM 符号编码

### 3.2 CNN 残差 Decoder（参考 NNreceiver）

- **特征图**：`[channel_emb(64) + LWM 浅层特征(3~6层, 256) + H_patch(16) + Re/Im(z) + σ²
  + mod_onehot(4) + 配置元数据(14)]` = 357 通道（补零到 358 满足 GroupNorm(2)），
  布局 (B, 358, n_symb, n_sc)；浅层特征提供多尺度信道模式
- **结构**：GroupNorm(2) → 3×3 转置卷积（64 通道）→ 11 个残差块（空洞可分离卷积，
  out_channels `[64,64,128,128,256,256,256,128,128,64,64]`，dilation
  `[(1,1),(1,1),(2,3),(2,3),(2,3),(3,6),(2,3),(2,3),(2,3),(1,1),(1,1)]`）→ 3×3 卷积 → 8 通道 logits
- **输出**：全网格 logits → 按样本 `data_re_idx` 取数据 RE → (B, n_data, 8)，裁剪 ±MAX_LLR
- 全卷积结构对网格尺寸自适应；z 仅数据 RE 有值，空洞卷积利用邻近 RE 上下文
- **配置元数据通道**（14 维）：天线数/RB/符号数/DMRS 模式/TDL/速度——接收机已知的
  系统参数，帮助模型在小数据下区分配置

### 3.3 损失函数

有效 RE × 有效比特掩码上的 **BCE（binary cross-entropy with logits）**，标签为
真实传输的 0/1 bit：直接优化分类正确率（BER），无需理想 LLR 标签；支持 batch 内
混合调制阶数（超出 log2M 的比特通道被掩码）。

### 3.4 训练策略

- 两阶段：MCM 继续预训练（mask 15% 子载波 patch 重建）→ LLR 微调（BCE）
- **LLR 微调为两阶段**：阶段2a 冻结骨干只训 decoder（20 epoch，lr=1e-4）；
  阶段2b 解冻骨干联合微调（20 epoch，骨干 lr=1e-4），充分发挥骨干适配价值
- 多配置数据按 (n_sc, n_symb, n_rx, n_data) 分桶，batch 内同配置（CNN 特征图尺寸一致）
- 每配置组合 8 个不同样本
- 6GB 显存：batch=8 + 梯度累积=8（等效 64）

## 4. 训练过程（GPU 大规模）

| 阶段 | 配置 | 结果 | 耗时 |
|------|------|------|------|
| 阶段1 MCM | 2000 样本（250 组合×8），15 epoch | loss 0.93 → **0.245** | ~2.5 min |
| 阶段2 主模型 | 2400 样本（300 组合×8），两阶段 20+20 epoch | val BCE 0.671 → **0.253**，valBER 0.413 → **0.109** | ~8 min |
| 阶段2 对照 | 同主模型（官方权重，无预训练） | val BCE 0.671 → **0.254**，valBER 0.413 → **0.109** | ~8 min |
| 数据缓存 | 4560 样本（pkl 复用） | — | 首次 ~6.5 min |

> 小规模预实验（400 样本 / 12~30 epoch / 无 cfg 通道）：模型仅低 SNR 有增益、
> 20dB 劣化（0.17 vs 0.05），验证了"每配置多样本 + cfg 通道 + 大规模训练"的必要性。

## 5. 性能评估（48 样本 = 6 SNR × 8 配置循环）

### 5.1 硬判决 BER vs SNR（越低越好）

| 0 dB | 0.3426 | 0.2545 | **-25.7%** ✅ | 0.2564 |

| 15 dB | 0.0770 | 0.0201 | **-73.9%** ✅ | 0.0229 |

### 5.3 LLR 指标（BCE logits 与 max-log 尺度不同，仅参考）

| 方案 | MSE | 相关系数 |
|------|-----|---------|
| 传统基线（H_est） | 4.40 | 0.886 |
| LWM + CNN（本方案） | 94.8 | 0.695 |
| 对照（无预训练） | 96.4 | 0.695 |

> 模型学的是**后验概率 LLR**（logit = log p/(1-p)），与 max-log 参考尺度不同，
> MSE/相关不直接可比；其硬判决正确率显著优于基线，对下游软判决译码是更优校准。

### 5.4 结论与已知现象

1. **一个模型适配所有系统参数成功**：-5~20 dB 全区间 BER 改善 8.7%~73.9%，各配置
   维度（天线/RB/符号/DMRS/TDL/多普勒）全部无劣化。
2. **高 SNR 增益最大**（10~15dB ~ -55%~-74%）：模型学会了各配置下对 LS 信道估计
   误差的系统性修正。
3. **继续预训练 vs 官方权重**：两阶段联合微调（骨干 lr=1e-4）后两者性能接近
   （主模型 15~20dB 略优）——骨干大 lr 微调使模型快速适应当前任务，MCM 初始化
   差异被覆盖；整体性能相对基线显著提升（见 §6）。
4. 评估采样：每 SNR 8 样本按配置循环覆盖（含 1rx/1RB 等困难配置），基线 BER 显著
   高于固定配置场景，更贴近真实部署难度。

## 6. 后续改进

1. **继续预训练价值**：两阶段联合微调（骨干 lr=1e-4）后主 vs 对照接近，MCM 初始化
   差异被大 lr 微调覆盖——可尝试 MCM 预训练用更大 lr/更长 epoch，或联合微调阶段
   对骨干用更小 lr（如 1e-5）以保留域适配先验。
2. **端到端评估**：接入 5G NR LDPC 译码器，用 BLER 作为最终落地指标（本方案的 LLR
   是后验概率 logits，天然适合软判决译码）。
3. **模型结构探索**：CNN decoder 的可分离卷积/转置卷积开关、dilation 配置；取 LWM
   浅层（3~6 层）特征。
4. **信道场景扩展**：更多时延/多普勒组合、多 UE 干扰、更大系统带宽（20MHz/50MHz）。
5. **更强基线对比**：LMMSE 插值器（`LMMSEInterpolator`）、迭代接收机。
